# Документация Lumivox Devicelab

[English version](../en/README.md) | [Основной README](../../README.md)

Lumivox Devicelab предоставляет синхронный Python API для захвата звука с
микрофона, вывода на динамики и чтения WAV/FLAC в Linux. Обработку медиа
выполняет GStreamer, а PipeWire с WirePlumber используются для обнаружения и
маршрутизации устройств.

## Область применения

Поддерживается:

- неизменяемые снимки доступных микрофонов и динамиков;
- захват с микрофона через синхронный обработчик;
- чтение WAV и FLAC в реальном времени или с максимально возможной скоростью;
- синхронная потокобезопасная передача звука на динамик с обратным давлением,
  ограниченным на обычных звуковых частотах (см. [ограничения](guarantees.md));
- дополнительная запись микрофона или воспроизводимого звука в WAV/FLAC;
- автоматическое восстановление после определенных ошибок источника микрофона.

Пока не поддерживается:

- Windows и macOS;
- конфигурации только с PulseAudio и менеджеры сессий, отличные от WirePlumber;
- видео и произвольная обработка медиа;
- подписка на подключение устройств и изменение устройства по умолчанию;
- автоматический переход на устройство по умолчанию при недоступности
  настроенного устройства;
- нативный asyncio API, VAD, эхоподавление, распознавание и синтез речи.

## Основной контракт

Все публичные аудиобуферы являются interleaved PCM-массивами NumPy с dtype
`numpy.dtype("<i2")`:

- форма mono: `(frames,)`;
- форма многоканального звука: `(frames, channels)`;
- частота дискретизации и число каналов задаются `AudioFormat`;
- представление: знаковый 16-битный little-endian PCM (`S16LE`).

Каждый объект, создающий логи, требует явный `Logger` из Lumivox Core.
Приложение самостоятельно настраивает логирование. Библиотека не настраивает
его неявно и не раскрывает объекты GStreamer или PipeWire в публичном API.

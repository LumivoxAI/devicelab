# Файловые элементы GStreamer

Этот модуль содержит внутренние обёртки над элементами GStreamer для WAV- и FLAC-файлов. Общие инварианты внутреннего GStreamer-слоя описаны в `../README.md`. Декодированный аудиопоток перед передачей в Devicelab должен быть нормализован элементами `AudioConvert`, `AudioResample` и `CapsFilter` к контракту `RawAudioSpec`: interleaved PCM `S16LE` с требуемыми частотой дискретизации и числом каналов.

Обёртки создают GStreamer-элемент сразу. Если требуемая фабрика плагина недоступна, создание завершается `GStreamerElementError`; ошибки открытия, чтения, декодирования или записи файла поступают через bus pipeline при запуске.

## FileReplayMode

Публичный `FileReplayMode` из `lumivox_devicelab.file_capture` описывает политику файлового входа:

| Значение | Значение для pipeline |
| --- | --- |
| `realtime` | Сохранять временные метки файла и воспроизводить поток в реальном времени, имитируя микрофон. |
| `as_fast_as_possible` | Не ожидать временные метки и обрабатывать файл с максимально доступной скоростью. |

Сам `FileSrc` эту политику не применяет: `filesrc` не синхронизируется с clock и только читает байты. `FileCapturePipeline` явно добавляет нужные элементы синхронизации.

## FileSrc

`FileSrc` является обёрткой над `filesrc` и читает байты из файла. Его исходный pad имеет caps `ANY`: элемент не определяет контейнер и кодек, поэтому после него должен располагаться подходящий parser.

```python
FileSrc("input.wav")
```

| Аргумент | Значение | Политика |
| --- | --- | --- |
| `location` | `str` или `os.PathLike[str]` | Передаётся в свойство `filesrc.location`. Пустая строка отклоняется с `ValueError`. |
| `name` | `str | None` | Необязательное имя GStreamer-элемента. |

Путь устанавливается до запуска pipeline. Существование файла, права доступа и корректность содержимого не проверяются конструктором.

## FileSink

`FileSink` является обёрткой над `filesink` и последовательно записывает полученные буферы в файл. Он не кодирует аудио и не создаёт WAV- или FLAC-контейнер сам: перед ним должен находиться соответствующий encoder.

```python
WavEnc().link(FileSink("recording.wav"))
```

| Свойство | Значение | Дефолт GStreamer | Политика |
| --- | --- | --- | --- |
| `location` | Переданный путь | `null` | Указать файл назначения; пустой путь отклоняется с `ValueError`. |
| `sync` | `False` | `False` | Не задерживать запись до времени буфера. Скорость записи определяется доступностью downstream I/O. |

По умолчанию `filesink` открывает файл с усечением существующего содержимого. Режим добавления, размер буферов и режим файлового I/O этой обёрткой не настраиваются.

`sync=False` не означает, что запись гарантированно не блокирует поток: медленный диск всё ещё может создать backpressure. Для recording pipeline это ожидаемая политика, поскольку полнота записи важнее одновременной низколатентной playback.

## WAV

### WavParse

`WavParse` является обёрткой над `wavparse`. Элемент разбирает WAV-контейнер, извлекает аудиопоток и публикует negotiated raw-audio caps. Он не приводит поток к контракту Devicelab и не преобразует частоту дискретизации, разрядность или число каналов.

Типичная входная цепочка:

```text
filesrc -> wavparse -> audioconvert -> audioresample -> capsfilter
```

### WavEnc

`WavEnc` является обёрткой над `wavenc`. Элемент упаковывает согласованный raw-аудиопоток в WAV-контейнер; последующий `FileSink` записывает сформированный поток в файл.

Типичная цепочка записи:

```text
raw audio -> wavenc -> filesink
```

Формат WAV определяется negotiated caps на входе `wavenc`. Перед encoder-ом pipeline должен обеспечить совместимый raw-аудиоформат; если требуется записывать нормализованный поток Devicelab, им является `audio/x-raw,format=S16LE,layout=interleaved` с явно заданными `rate` и `channels`.

## FLAC

### FlacParse

`FlacParse` является обёрткой над `flacparse`. Он разбирает входящий FLAC-поток и выдаёт фреймированные caps `audio/x-flac`. `FlacParse` не декодирует сэмплы, поэтому для получения raw-аудио после него требуется `FlacDec`.

### FlacDec

`FlacDec` является обёрткой над `flacdec`. Он декодирует фреймированный FLAC в raw-аудиопоток. Как и для WAV, полученный формат определяется файлом и negotiated caps; перед границей Devicelab его следует нормализовать аудиоэлементами модуля `audio`.

Типичная входная цепочка:

```text
filesrc -> flacparse -> flacdec -> audioconvert -> audioresample -> capsfilter
```

### FlacEnc

`FlacEnc` является обёрткой над `flacenc`. Он кодирует raw-аудио в lossless FLAC-поток с caps `audio/x-flac,framed=true`; `FileSink` записывает этот поток в файл.

```python
FlacEnc(quality=5)
```

| Аргумент | Значение | Дефолт GStreamer | Политика |
| --- | --- | --- | --- |
| `quality` | Целое от `0` до `9` | `5` | Компромисс между скоростью кодирования и степенью сжатия. `0` выбирает наиболее быстрое, `9` -- наиболее ресурсоёмкое сжатие. Некорректное значение отклоняется с `ValueError`. |
| `name` | `str | None` | Автоматическое имя GStreamer | Необязательное имя элемента. |

Качество не влияет на lossless-характер кодирования: декодированный поток сохраняет значения входных сэмплов. Более высокое значение может потребовать больше CPU и потому не гарантирует пригодность для низколатентной одновременной записи и playback.

Типичная цепочка записи:

```text
raw audio -> flacenc -> filesink
```
